# 统计模块

> 统计计算与展示，嵌入 [我的模块](./mine-page.md) 的"我的"页面中。无独立页面，以卡片形式呈现。

## 子任务

### 1. 本周统计卡片

- [ ] 1.1 在 `pages/mine/` 中实现统计卡片区域 UI（或创建独立组件 `components/stats-cards/`）
- [ ] 1.2 卡片 1：本周任务总数（蓝色）
- [ ] 1.3 卡片 2：本周完成任务数 + 完成率百分比（绿色）
- [ ] 1.4 卡片 3：本周习惯达标数（紫色）
- [ ] 1.5 卡片 4：本周最长连续打卡（橙色）
- [ ] 1.6 卡片布局：白色圆角卡片网格，每张卡片含数字 + 标签文字

### 2. 本周任务统计

- [ ] 2.1 计算本周日期范围（周一 ～ 周日），使用 `utils/date.js`
- [ ] 2.2 查询本周所有任务：`tasks.where({ date: _.gte(startDate).and(_.lte(endDate)) })`
- [ ] 2.3 统计：总任务数、已完成数、完成率 = 已完成 / 总数（百分比，整数）

### 3. 本周习惯统计

- [ ] 3.1 查询本周所有 checkins：`checkins.where({ date: _.gte(startDate).and(_.lte(endDate)) })`
- [ ] 3.2 统计：每天打卡的习惯数 → 本周每天都打卡的习惯数（7 天全部打卡才算"达标"）
- [ ] 3.3 显示习惯达标数

### 4. 习惯详细统计

- [ ] 4.1 展示每个习惯的当前连续天数（streak）
- [ ] 4.2 展示每个习惯的历史最长连续天数（best_streak）
- [ ] 4.3 列表样式：习惯名称 + `${streak}天🔥` + `${best_streak}天最长`

### 5. 数据刷新

- [ ] 5.1 每次进入"我的"页面时刷新统计
- [ ] 5.2 使用 `wx.showNavigationBarLoading()` 显示加载状态
- [ ] 5.3 加载完成后隐藏导航栏 loading
- [ ] 5.4 查询失败时卡片显示"--"并提示重试
