# LearnLab 需求设计文档

> 版本 1.0 · 2026-05-16 · 状态：待评审

## 一、产品概述

**LearnLab** 是一款微信小程序，面向小群体用户的每日学习计划 + 习惯养成工具。用户可以规划每日学习任务、追踪习惯打卡、浏览日历、查看简单统计。用户之间各自独立使用，数据互不可见。

## 二、目标用户与使用场景

- **用户**：小群体内独立使用（如班级、学习小组），每人只看自己的数据
- **场景**：当天早上/前一天晚上写好计划，当天逐个勾选完成
- **平台**：微信小程序
- **设备**：手机端

## 三、核心功能

### 3.1 每日计划
- 今日视图（默认首页）：显示当日所有任务
- 每条任务包含：任务名称、开始时间、结束时间、预计时长、优先级（高/中/低）、完成勾选、备注
- 添加任务：弹窗表单（黑色底色，白色输入框）
- 编辑任务：点击卡片弹出编辑弹窗（预填已有数据）
- 删除任务：左滑卡片出现删除按钮
- 完成切换：点击卡片左侧圆圈直接切换完成状态
- 日期切换：左右箭头或点击日历图标切换日期
- 输入开始/结束时间后，预计时长自动计算

### 3.2 日历视图
- 首页顶部切换按钮，在"今日视图"和"日历视图"间切换
- 月历组件：显示当月完整日历
- 有任务的日期标注小圆点
- 点击某天显示该日概要（任务数、总时长）
- 左右箭头切换月份
- 点击"切换到今日视图"跳转到选中日期

### 3.3 习惯打卡
- 独立底部 Tab 页面
- 习惯列表：显示名称、连续天数（🔥图标）、今日是否完成
- 顶部进度条：今日完成进度（X/N）
- 勾选/取消今日打卡
- 新建习惯：输入名称即可
- 编辑/删除习惯：长按或左滑

### 3.4 统计（"我的"页面内）
- 本周统计卡片：完成任务数、完成率、习惯达标数
- 每个习惯的连续天数、最长记录

### 3.5 "我的"页面
- 微信头像 + 昵称（自动获取）
- 本周统计卡片
- 数据导出
- 设置
- 关于
- 退出登录

## 四、页面与导航

```
底部 Tab 栏：
┌──────────┬──────────┬──────────┐
│  📋 首页  │  ✅ 习惯  │  👤 我的  │
└──────────┴──────────┴──────────┘

首页（默认今日视图）
  ├─ 日期选择器（左右滑动 / 日历图标）
  ├─ 任务列表（紧凑卡片）
  ├─ + 添加任务 按钮
  └─ 切换 → 日历视图（月历 + 日期概要）

习惯
  ├─ 今日进度条
  ├─ 习惯列表 + 打卡
  └─ + 新建习惯

我的
  ├─ 用户信息
  ├─ 统计概览
  ├─ 数据导出
  ├─ 设置
  └─ 关于
```

## 五、数据模型

### 任务（tasks）
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 自动生成 |
| name | string | 任务名称（必填） |
| date | string | 所属日期 YYYY-MM-DD |
| start_time | string | 开始时间 HH:mm |
| end_time | string | 结束时间 HH:mm |
| duration | number | 预计时长（分钟） |
| priority | string | "high" / "medium" / "low" |
| completed | boolean | 是否完成（默认 false） |
| notes | string | 备注（可选） |
| _openid | string | 所属用户（微信自动注入） |

### 习惯（habits）
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 自动生成 |
| name | string | 习惯名称 |
| streak | number | 当前连续天数 |
| best_streak | number | 历史最长连续天数 |
| last_checkin_date | string | 上次打卡日期 |
| _openid | string | 所属用户 |

### 打卡记录（checkins）
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 自动生成 |
| habit_id | string | 关联习惯 ID |
| date | string | 打卡日期 YYYY-MM-DD |
| _openid | string | 所属用户 |

## 六、技术方案

| 项 | 选择 |
|----|------|
| 前端框架 | 微信小程序原生（WXML + WXSS + JavaScript） |
| 后端云服务 | 微信云开发（云数据库 + 云函数 + 云存储） |
| 用户鉴权 | 微信授权登录，云开发天然集成 |
| 数据隔离 | 云数据库按 _openid 自动隔离 |
| 提醒 | 不需要 |

## 七、设计风格

- 弹窗底色：黑色（#1e1e1e）
- 输入框：白色
- 主色调：紫色（#6366f1）
- 页面底色：浅灰（#f5f5f5）
- 任务卡片：白色圆角，带阴影
- 习惯绿色主题
- 优先级颜色：高=红、中=黄、低=绿

## 八、不包含的功能（明确排除）

- 不包含消息提醒/推送
- 不包含用户间数据互看
- 不包含长期目标自动拆解
- 不包含周循环课表模式
- 不包含离线使用（需要网络）
- 不包含详细图表报表（热力图、趋势图等）
