# LearnLab 界面 UI 优化更新 — 设计文档

> 版本 1.0 · 2026-05-17 · 基于概要设计 [learn-lab-design.md](./learn-lab-design.md) · 基于交互修复设计 [2026-05-16-task-interaction-fix-design.md](./2026-05-16-task-interaction-fix-design.md)

## 一、背景与目标

### 1.1 现状问题

LearnLab 当前设计为**标准扁平风格**——白色卡片 + 单一紫色主色（#6366f1）+ 浅灰背景。经设计审计发现以下主要问题：

| # | 问题 | 影响 |
|---|------|------|
| 1 | 无深色模式 | 移动端主流体验缺失 |
| 2 | 单一阴影体系 | 所有卡片同一阴影，无层级感 |
| 3 | 间距偏紧 | 页面内边距仅 16rpx，缺乏呼吸感 |
| 4 | 字号层级压缩 | 仅 4 级字号（24-36rpx），标题与正文区分弱 |
| 5 | 卡片风格雷同 | 任务/习惯/统计/日历卡片外表完全一致 |
| 6 | 无过渡动画 | 弹窗/页面切换无动效，体验生硬 |
| 7 | 硬编码色值散落 | 多处 hex/rgba 直接写死，无法主题化 |
| 8 | 品牌色大众化 | Indigo-500 是 Tailwind 默认色，缺乏辨识度 |

### 1.2 设计目标

- **风格方向**：深色极简风（Dark Minimal），teal/cyan 科技感配色
- **覆盖范围**：全局深色主题 + 浅色可切换，所有页面/组件统一改造
- **实施深度**：中度焕新——重构 token 体系 + 优化视觉层次 + 基础动画
- **约束条件**：功能不变，WXML 结构不改，JS 逻辑不改，云函数不改

## 二、设计方向选择

### 2.1 风格方向

**深色极简风（Dark Minimal）**

- 全局深色主题，深绿黑底色（`#080c0c`）
- 微弱边框代替阴影来区分层级
- Teal/cyan 霓虹点缀色
- 参考：Linear、VS Code 暗色主题

### 2.2 色彩性格

**青碧赛博（Teal Cyber）**

- 主色：`#14b8a6`（Teal-500），清新冷静，科技感
- 底色：极深绿黑 `#080c0c`，比纯黑更有层次
- 点缀：cyan 渐变（`#2dd4bf` → `#5eead4`）用于强调

## 三、色彩系统 & 设计 Token

### 3.1 核心原则

- **语义化命名**：组件只引用 `--color-surface`、`--color-text-primary` 等语义 token，不直接写 hex
- **双主题映射**：同一个语义 token 在深色/浅色下映射到不同色值
- **统一替换**：所有现有硬编码色值（`#666`、`#8b5cf6`、`#f97316`、`rgba(...)` 等）全部替换为语义 token

## 四、阴影 & 层级体系

深色主题下阴影不可见，用**边框深度**替代。浅色主题用柔和阴影。

| 层级 | 用途 | 深色表现 | 浅色表现 |
|---|---|---|---|
| Level 0 | 页面背景 | 无 | 无 |
| Level 1 | 卡片（task-card, habit-card, calendar, stats-cards） | `1px solid #1e2a2a` | `0 1px 4px rgba(0,0,0,0.04)` |
| Level 2 | 弹窗 / FAB | `1px solid #2a3a3a` | `0 4px 16px rgba(0,0,0,0.08)` |
| Level 3 | Toast / 提示条 | `1px solid #3a4a4a` + box-shadow 微发光 | `0 8px 24px rgba(0,0,0,0.12)` |

新增 CSS token：
- `--shadow-card`：映射到上述 Level 1
- `--shadow-modal`：映射到上述 Level 2
- `--shadow-toast`：映射到上述 Level 3

## 七、动画体系

全部使用 CSS `transition` 实现，不引入 JS 动画库。遵守 `prefers-reduced-motion`。

| 场景 | 方案 | 时长 | 缓动 |
|---|---|---|---|
| 卡片入场（首页加载） | `opacity` 0→1 + `translateY` 8rpx→0，逐张 stagger 50ms | 200ms/张 | ease-out |
| 弹窗打开 | 遮罩 opacity 0→1 + 内容 translateY 100%→0 | 200ms | ease-out |
| 弹窗关闭 | 遮罩 opacity 0 + 内容 translateY 0→100% | 150ms | ease-in |
| 按钮/卡片按下 | opacity 1→0.85 | 100ms | ease |
| 任务完成切换 | 圆圈背景色填充过渡 + 卡片整体 opacity 过渡 | 200ms | ease |
| 主题切换 | 全局 `background-color` + `color` + `border-color` 渐变 | 300ms | ease |
| 列表项删除 | max-height 收缩 + opacity 淡出 | 200ms | ease-in |
| 进度条更新 | width 过渡 | 300ms | ease-out |

    ↓
